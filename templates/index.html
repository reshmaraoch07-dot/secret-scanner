    DevSecOps CI/CD Demonstration Guide

    This project demonstrates how security scanning can be embedded directly into a DevOps CI/CD pipeline using GitHub Actions.

    1

    CLI Scanner Execution

    Run the scanner in any terminal without launching Flask:

    python scanner.py .
    • Returns Exit Code 0 if no secrets are found (Pipeline Passes).
    • Returns Exit Code 1 if exposed secrets are detected (Pipeline Fails).
    2

    GitHub Actions Workflow

    The file .github/workflows/security-scan.yml triggers on every git push or pull request.

    name: Secret Scanner CI/CD
on: [push, pull_request]
jobs:
  security-scan:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: '3.11'
      - run: pip install -r requirements.txt
      - run: python -m unittest discover tests
      - run: python scanner.py .
    3

    College Presentation Demo Steps

    Demo 1 — Safe Code (Pipeline Passes):

    # example.py
name = "Student"
age = 20
print("Welcome to Secret Scanner Demo")

    Execute python scanner.py . → ✅ SECURITY SCAN PASSED

    Demo 2 — Exposed Secret (Pipeline Fails):

    # example.py
name = "Student"
password = "YOUR_EXPOSED_PASSWORD"  # Hardcoded secret!

    Execute python scanner.py . → ❌ SECURITY SCAN FAILED (Exit Code 1 blocks build)

    ⚠️ Project Notice: This tool detects pattern-based credentials. It does not validate or connect to live services. Developed for College DevOps/DevSecOps Demonstration.
